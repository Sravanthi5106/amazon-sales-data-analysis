# 📊 Amazon Sales Data Analysis (Task 1)

## 📌 Project Overview
This project focuses on data cleaning and preprocessing of an Amazon sales dataset as part of a Data Analytics Internship.

---

## 📂 Dataset
The dataset includes:
- Order details
- Product categories
- Pricing and discounts
- Customer regions
- Ratings and reviews

---

## 🔍 Data Cleaning Steps
- Checked dataset structure
- Handled missing values using forward & backward fill
- Removed duplicate records
- Fixed date format issues
- Validated revenue calculations
- Removed invalid (negative) values
- Created new features:
  - Month
  - Year
  - Discount Level

---

## 📁 Files Included
- `amazon_sales_dataset.csv` → Raw dataset  
- `cleaned_amazon_sales_dataset.csv` → Final cleaned dataset  
- `Task1Analysis.py` → Code file  

---

## 🚀 Outcome
The dataset is cleaned and ready for Exploratory Data Analysis (EDA) and machine learning.
